# Repositorio retirado

El código de este proyecto **ya no se aloja en GitHub**.

Desde agosto de 2026 el origen de verdad es local, tras los ataques encadenados
de cadena de suministro del año —Shai-Hulud, ChainDrop, y la extensión maliciosa
de VS Code que expuso miles de repositorios privados—. Ser privado dejó de
significar estar a salvo: en todos esos casos lo que cayó fue la **cuenta**, no
el repositorio.

Este espacio se conserva solo para no liberar el nombre.
